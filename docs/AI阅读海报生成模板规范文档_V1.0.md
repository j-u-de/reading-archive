# AI阅读海报生成模板规范文档 V1.0

## 项目目标

生成一套长期可复用的 AI 阅读海报系统。

目标效果：接近高级图书封面、文学出版物视觉、博物馆展览海报；
不是阅读App信息卡片，不是营销活动海报，不是PPT页面。

核心原则：

**固定结构，不固定视觉；统一模板，不复制风格。**

## 核心设计原则

所有海报必须同时满足：

1. 品牌统一性
2. 书籍独特性
3. 视觉艺术性

每一本书必须拥有独立视觉表达，而不是只替换标题和背景。

## 固定版式结构

保持统一布局：

1. 顶部系列标识 / 阅读栏目
2. 主标题区域
3. 副标题 / 核心观点
4. 视觉主体区域
5. 一句话阅读价值
6. 关键词 / 分类信息
7. 作者信息

## 视觉设计要求

整体风格：

- 高级图书封面
- 文学出版视觉
- 展览海报
- 杂志专题封面

要求：

- 克制
- 留白
- 有书卷气
- 有叙事感
- 有收藏价值

禁止：

- App UI感
- 玻璃拟态卡片
- PPT页面感
- 活动宣传图感
- 社交媒体标签风

## 核心视觉规则

每本书必须提炼一个核心视觉隐喻。

要求：

- 单一
- 明确
- 有象征意义
- 能代表书籍精神

## 构图规范

要求：

- 大量留白；
- 标题区域干净；
- 主视觉明确；
- 采用出版物排版逻辑。

避免：

- 元素堆叠；
- 全画面高密度细节；
- 多个无关视觉主体。

## 字体规范

标题：

- 中文优先使用具有出版感的字体；
- 具有书卷气、历史感、文化感。

正文：

- 简洁易读；
- 控制文字数量；
- 避免说明书式文本。

## 文案规范

正文控制：

40-80字以内。

结构：

作者/作品背景 + 核心价值 + 阅读意义。

禁止：

- 长篇介绍；
- 百科说明；
- 书评式文字。

## 材质与色彩

推荐：

- 纸张纹理
- 胶片颗粒
- 墨迹
- 木质
- 旧物质感

增强：

- 时间感
- 阅读感
- 收藏感

颜色根据书籍主题变化：

- 历史：深红、棕色、米白、暗金
- 文学：黑白、暖灰、柔和色
- 商业：深蓝、灰色、金属色
- 科普：蓝紫、冷色、未来感
- 成长：绿色、暖光、自然色

## 生成流程

Step 1：理解书籍：类型、核心主题、情绪、时代背景。

Step 2：提炼一个核心视觉隐喻。

Step 3：确定：视觉方向、色彩、材质、构图、字体气质。

Step 4：生成最终海报。

## 质量验收标准

检查：

### 阅读属性

- 是否体现书籍气质？
- 是否一眼看出阅读主题？

### 艺术性

- 是否有明确主视觉？
- 是否具有收藏价值？

### 信息设计

- 标题是否突出？
- 信息是否简洁？

### 高级感

- 是否像出版物？
- 是否避免AI廉价感？

## Codex执行指令

请基于以上规范开发 AI 阅读海报生成模板。

必须满足：

1. 固定版式结构，不固定视觉主题；
2. 每本书必须生成独立视觉隐喻；
3. 输出效果接近高级书籍封面；
4. 减少信息堆叠，强化留白；
5. 根据书籍类型自动调整视觉语言；
6. 严格避免UI感、PPT感、商业活动海报感。

最终目标：

批量生成1000张海报时，每张仍然具有独立审美和收藏价值。
