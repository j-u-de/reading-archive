# Changelog

## 2.0 - 2026-09-06
- 以 1.0 初始化版本为基础，完成书架、阅读会话、统计、报告、AI 分析、海报和设置的完整应用闭环。
- 将同一本书的多次阅读建模为独立 Reading Session，保留历史进度和 Progress Log，并兼容旧版 localStorage 数据迁移。
- 增加书籍联网候选、手动创建、来源和日期；联网搜索与 AI 解析保持独立，搜索失败不阻塞本地书架。
- 增加阶段性阅读报告、最近完成、趋势统计、主题词云、共性分析和分支分析。
- 完善 AI 阅读解析、主题持久化、Provider 设置和失败处理；实际调用依赖模型配置与服务商可用性。
- 增加 3:4 阅读海报生成、主题导向、海报保存和再次选中时恢复历史海报。
- 重组底部导航和功能页面，将 AI 主题分析归入报告，将阶段性报告和最近完成归入统计。
- 优化阅读日历的固定日期格、展开查看、状态颜色、导航栏、月份选择和弹窗交互。
- 增加可选 Supabase REST 同步适配器与 `/api/sync`，同步失败时安全回退本地模式。
- 移除部署实验产生的 Cloudflare 配置、工作流和专用依赖，项目运行依赖回归本地 Next.js 应用。
- 修复开发服务器与生产构建共用 `.next` 缓存导致的模块缺失问题，开发缓存改用 `.next-dev`。
- 按所有者要求提交本地书架快照，包含 53 本书、55 次阅读及已有图片数据；不提交 API 密钥。
- 建立 1.0 与 2.0 独立分支和固定标签，补充版本入口、运行条件、开发过程和数据边界文档。
- 统一 pnpm 锁文件，移除指向 Next.js 14 的旧 npm 锁文件；更新适配 Next.js 15 的 lint 命令及失败即停止的 QA 脚本。

## 1.0 - 2026-08-31

以下为初始化版本既有记录，保留其历史描述；当前行为以 2.0 文档和代码为准。
- 初始化 Reading Archive PWA 基础工程与 Liquid Glass 视觉层。
- 建立书籍、阅读会话、进度日志及 AI 相关数据模型。
- 增加本地书架、进度操作、统计、报告、设置、海报和 AI Provider 兜底接口。
- 增加 Chrome 回归检查与隔离开发/构建缓存目录。
- 会话化重构：同一本书支持多次 Reading Session，旧版 localStorage 自动迁移。
- 添加书籍支持联网候选、手动创建、阅读来源和日期；详情页支持页码/章节与 Progress Log。
- 增加统计趋势、阶段性报告、AI 笔记编辑保存、AI 主题标准化持久化和 3:4 海报渲染。
- 增加可选 Supabase REST 同步适配器与 `/api/sync`，未配置时安全回退本地模式。
