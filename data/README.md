## 使用边界

当前应用不会自动读取这个磁盘文件，也没有上传 JSON 的设置入口。它是供后续迁移和恢复的版本备份。恢复适配需要先将内嵌图片写入 IndexedDB，再通过应用档案逻辑保存图片引用与结构化记录；不要将整个文件直接写入 Local Storage。

浏览器后续新增或修改不会自动更新 Git 文件；每次新增备份都应明确导出、校验并提交。源码版本、浏览器数据和这个文件是不同的存储位置。

文件包含个人阅读信息，能够访问仓库或下载此版本的人也能读取这些记录。环境文件和模型密钥不属于这份档案，继续保存在本机。
